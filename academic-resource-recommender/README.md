# Academic Resource Recommendation Engine

Group project website built with plain HTML, CSS and JavaScript.

## How to run
Open `index.html` in any browser. No installation or server is needed.

## Pages
| Page | Purpose | CSS | JS |
|------|---------|-----|----|
| index.html | Home, numbers, top rated resources | home.css | home.js |
| catalogue.html | Resource catalogue with search and filters | catalogue.css | catalogue.js |
| interests.html | Choose topics of interest | interests.css | interests.js |
| tags.html | Browse by course and topic tags | tags.css | tags.js |
| recommendations.html | Rule based recommendations | recommendations.css | recommendations.js |
| ratings.html | Rate resources | ratings.css | ratings.js |
| bookmarks.html | Saved resources | bookmarks.css | bookmarks.js |
| feedback.html | Feedback form | feedback.css | feedback.js |
| admin.html | Add and delete resources (password: admin123) | admin.css | admin.js |
| about.html | Team and project details | about.css | about.js |

Shared files: `css/common.css` (navigation, cards, buttons, forms) and `js/data.js`
(sample resources and helper functions used by every page).
